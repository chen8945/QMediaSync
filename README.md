<h1 align="center">QMediaSync</h1>

<p align="center">连接网盘与 Emby，让媒体同步与刮削更简单。</p>

QMediaSync 是一个开源的媒体同步与刮削工具，支持 115 网盘、百度网盘、OpenList 及本地挂载目录，提供文件同步、STRM 生成和影视元数据刮削功能，并支持与 Emby、飞牛影视联动。

## Docker 镜像

`ghcr.io/chen8945/qmediasync:latest`

从原项目迁移时，只需要将 Docker 镜像地址更换为以上地址。
