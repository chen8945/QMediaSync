# Emby 外网 302 播放

QMediaSync 内置一个 Emby 代理入口。播放器连接这个入口后，QMediaSync 会为支持的网盘 STRM 解析播放地址；例如 115 网盘通常可以让播放器直接读取网盘视频，减少服务器转发视频的流量。

功能习惯上称为“Emby 302”，实际请求可能返回 HTTP `302` 或 `307`。它们都是跳转，不是播放成功的证明；不同来源也不一定都能绕过服务器转发。

## 先分清三个地址

下面以 QMediaSync 位于 `192.168.1.10`、Emby 位于 `192.168.1.20` 为例。地址和端口请替换为自己的实际值。

| 地址 | 填在哪里 | 谁需要能访问 |
| --- | --- | --- |
| 原 Emby 地址：`http://192.168.1.20:8096` | QMediaSync“系统设置 → Emby → Emby 服务器地址” | QMediaSync |
| QMediaSync 主服务：`http://192.168.1.10:12333` | “STRM 同步 → STRM 设置 → STRM 直连地址”；部分来源有差异，见下文 | Emby 和 QMediaSync |
| QMediaSync 的 Emby 代理：`http://192.168.1.10:8095` | 播放器中添加或修改的 Emby 服务器地址 | 实际使用的播放器 |

外网播放器需要能访问第三个地址，可以使用公网域名和反向代理。成功解析为网盘直链的情况下，前两个地址可以留在内网；**不要因为自己电脑能访问，就认为容器或外网播放器也能访问**。

## 配置与验证

1. 先确认原 Emby 能扫描到 STRM。遇到播放问题时，可按 [无法播放问题的排查步骤](Emby-无法播放问题的排查步骤.md) 检查。
2. 在 QMediaSync 的“系统设置 → Emby”填写原 Emby 地址，不要填写 QMediaSync 的 `8095` 代理地址，也不要附加 `/web/index.html`。
3. 点击“保存设置”，然后重启 QMediaSync。代理在启动时读取 Emby 地址，没有保存地址时不会启动监听。
4. Docker 部署确认已映射 `8095:8095`；使用内置 HTTPS 时还要映射 `8094:8094`。其他安装方式检查相应端口是否可达。
5. 在局域网打开 `http://192.168.1.10:8095`，使用原来的 Emby 账号登录，测试同一部影片。
6. **将播放器里的 Emby 服务器地址也改为代理入口。** 配好了 QMediaSync，但播放器仍连接原来的 `8096`，就没有使用这个代理。
7. 配好外网入口后，切到实际外网环境，用日常使用的播放器测试播放和拖动进度。

仅使用 302 代理本身，不要求在 QMediaSync 中填写 Emby API Key；媒体库条目同步、媒体信息提取和通知等管理功能需要它，见 [Emby 媒体库同步](Emby-媒体库同步.md)。

## 不同来源的播放方式

| 来源 | 需要了解的区别 |
| --- | --- |
| 115 网盘 | 通常解析为网盘直链，由播放器读取。取链和读取时的 User-Agent 需要匹配，换浏览器测试成功不能证明另一个播放器也可用。 |
| 百度网盘 | QMediaSync 会通过自己的代理携带百度要求的 User-Agent，视频流量会经过 QMediaSync；不能按纯网盘直连估算服务器带宽。 |
| OpenList | STRM 默认写入 OpenList 的下载链接。播放器需要能访问最终播放地址，是否直连或由 OpenList 转发还取决于 OpenList 和存储配置。 |
| 本地目录或挂载目录 | STRM 通常指向实际文件路径，由 Emby 读取；不会自动变成网盘直链，视频流量仍可能经过服务器。 |

远程 STRM 走直链时，需要播放器支持相应视频、音频和字幕格式。需要 Emby 转码时，用原 Emby 入口验证播放，不要假定直链代理可以代替转码。

如果 115 取链失败，代理可能回退到 STRM 原始地址。这个地址若只在内网可达，外网播放器就仍会失败。看到 `307` 或网盘域名还不够，必须确认实际视频能持续播放。

## HTTPS 入口

可以使用反向代理提供 HTTPS，再转发到内部的 `8095`，见 [反向代理配置](反向代理配置.md)。

也可以使用 QMediaSync 内置 HTTPS：

1. 准备与访问域名匹配的证书和私钥，分别命名为 `server.crt`、`server.key`。`server.crt` 建议包含完整证书链。
2. 放入实际使用的 `config` 目录。Docker 中是容器 `/app/config` 对应的宿主机目录；直接运行发布程序时，是程序同级的 `config`。
3. 重启 QMediaSync。证书变更不会自动热更新，更新后也要重启。
4. 通过与证书匹配的域名访问，例如 `https://emby.example.com:8094`。不要把这个示例域名当成自己的地址，也不要用与证书不匹配的 IP 地址替代。

两个证书文件都存在时，Emby 代理使用 HTTPS `8094`，原有 HTTP `8095` 保留。QMediaSync 管理页面的内置 HTTPS 端口是 `12332`，它与 Emby 代理入口不同。

## 修改 STRM 直连地址后

保存设置只改变之后生成链接所用的配置，**不会立即重写已有 STRM**。重新同步对应目录，再打开一个实际 STRM 文件检查里面的地址。

如果同步目录开启了“自定义 STRM 配置”，目录自己的“STRM 直连地址”会覆盖全局配置，也要一起检查。OpenList 默认使用账号中的 OpenList 地址，不能照搬其他来源的配置。
