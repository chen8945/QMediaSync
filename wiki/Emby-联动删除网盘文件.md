# Emby 联动删除网盘文件

开启后，在 Emby 中删除媒体并发送相应通知，QMediaSync 会核对文件归属，再删除对应的**网盘原文件**。这个功能适合希望在 Emby 中统一清理媒体的用户。

**QMediaSync 不能撤销网盘删除。** 某些情况下会清理整个媒体目录，目录内不认识的附件、子目录和未关联视频也会一起删除。数据库备份不包含网盘原片，不能用它恢复这些文件。

## 开启前先准备

1. 对准备使用的网盘同步目录执行一次完整的 STRM 同步，确认同步成功，让 QMediaSync 保存最新的文件记录。115 等提供“全量同步”按钮的来源，请使用全量同步；具体入口见 [生成 STRM](生成-STRM.md)。
2. 让 Emby 扫描这些 STRM，确认媒体已经入库。
3. 按 [Emby 媒体库同步](Emby-媒体库同步.md) 配好 Emby 地址和 Emby API Key，开启“启用同步”，保存后执行一次“启动全量同步”。升级后也应先完成一次全量同步，补齐版本、分段和目录归属信息。
4. 按 [Emby 通知配置](Emby-通知配置.md) 配置 Webhook、鉴权和媒体删除事件。先保持联动删除关闭，用可丢弃的测试媒体验证通知能送达。
5. 确认下面的删除范围符合预期后，在“系统设置 → Emby”开启“删除时联动删除网盘文件”，点击“保存设置”。
6. 先用专门准备的测试媒体检查实际结果，再用于日常清理。测试会真的删除对应网盘文件，不能用重要原片验证。

关闭期间收到的删除通知，以后开启也不会补删。如果删除前没有保存足够的文件关联信息，也不能靠事后同步补做删除。

## 哪些来源支持

| 来源 | 支持范围 |
| --- | --- |
| 115 网盘 | 核验通过后删除明确文件；符合条件时可清理整个媒体目录 |
| 百度网盘 | 核验通过后删除明确文件；符合条件时可清理整个媒体目录 |
| OpenList | 删除能确认归属的文件，不使用整目录清理 |
| 本地目录 | 不支持本功能的网盘联动删除 |

账号需要仍然有效。QMediaSync 还会确认文件是否属于原账号、是否还是原来的文件；无法确认时会保留文件。

## 不同删除操作会删什么

| 在 Emby 中删除 | QMediaSync 的处理范围 |
| --- | --- |
| 电影（Movie） | 删除该电影主项，以及确认属于它的合并分段；保留其他独立版本。符合目录清理条件时，可删除整个版本目录。 |
| 整部电视剧（Series） | 按已保存的真实剧集成员收集文件。符合条件时，可清理整部剧的目录。 |
| 一季（Season） | 按该季真实成员处理，最多清理该季自己的目录；不会根据“第 2 季”等目录名猜测范围。 |
| 单集（Episode） | 只删除该集主视频（分段视频中的 `part1`）和确认专属的 NFO、字幕、封面。`part2` 等其他分段保留，之后可能重新入库。即使删到最后一集，也不会自动删除季或剧目录。 |
| 独立视频（Video） | 只删除该视频和确认专属的元数据，不删除所在目录。 |

只有 QMediaSync 已确认整个目录属于要删除的电影、季或整剧，且没有明确需要保留的成员时，才会清理整个目录。**整目录清理会包含里面的陌生文件和子目录**，请不要把其他重要资料放在准备联动删除的媒体目录中。

如果 QMediaSync 已确认目录里还有需要保留的其他版本、季、作品或共享文件，就会保留目录，只处理能确认归属的文件。未被识别为保留成员的陌生文件，仍可能随整目录删除。同步根目录、其祖先目录和嵌套的同步根也受到保护。

网盘中刚被其他程序移动的文件，可能还没有同步到 QMediaSync。尤其不要在移动大量文件或调整目录的同时使用整目录联动删除；先完成 STRM 和 Emby 条目的全量核对，避免旧记录与实际位置不一致。

## 只想清理本地 STRM 时

**先关闭“删除时联动删除网盘文件”并保存，再删除本地 STRM。**

直接在文件系统删除 STRM、修改路径，或 Emby 扫描发现文件消失，都可能发出“媒体已移除”通知。不要把这个开关理解为“只有在 Emby 中手动点删除才会生效”。

Emby 通知中选择的媒体库决定是否发送通知；QMediaSync 中的“媒体库条目同步选择”决定同步哪些条目。两者都不能代替联动删除开关，也不是独立的删除白名单。

## 删除后到哪里看结果

收到通知后，QMediaSync 先保存事件，再在后台核验和删除。因此，Emby 显示通知发送成功，不代表网盘文件已经删除。

查看同一时间的 QMediaSync 服务日志，可以了解文件是否已删除、本来就不存在、核验未完成或删除失败。当前没有单独的联动删除任务页面。

- 原 Emby 条目或 STRM 仍存在、文件被其他条目共用、身份无法确认，或查询失败时，会保留网盘文件。
- 批量删除可能部分成功。视频和元数据不一定同时完成，应查看每个目标的处理结果；部分未完成操作会自动重试，停止重试的原因会记入日志。
- 网盘文件删除后，本地 STRM 和 QMediaSync 文件记录不会立即清除，会在之后满足清理条件的完整 STRM 同步中核对处理。
- 不要通过反复发送旧通知来扩大删除范围或补删历史文件。先根据日志确认缺少什么信息，再决定下一步操作。
