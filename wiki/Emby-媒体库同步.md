# Emby 媒体库同步

第一次接入 Emby 时，容易把几个“同步”混在一起。它们各自做的事情如下：

| 操作 | 做什么 | 从哪里操作 |
| --- | --- | --- |
| 生成 STRM | 把网盘或本地视频整理成 Emby 可以读取的 STRM 文件 | QMediaSync“STRM 同步”，见 [生成 STRM](生成-STRM.md) |
| Emby 扫描媒体库 | 让 Emby 发现 STRM，显示为电影或剧集 | Emby 媒体库扫描，或 QMediaSync 的“同步后刷新媒体库” |
| 同步 Emby 条目 | 把 Emby 已入库的条目信息记录到 QMediaSync，建立与网盘文件的关联 | QMediaSync“系统设置 → Emby”中的“启动全量同步” |
| 提取媒体信息 | 请 Emby 读取时长、音轨等信息 | [Emby 媒体信息提取](Emby-媒体信息提取.md) |

**“启动全量同步”读取的是 Emby 已有条目，不会命令 Emby 扫库。** 如果新影片还没出现在 Emby 中，应先检查 STRM 和 Emby 的媒体库扫描。

## 第一次配置

1. 先在 QMediaSync 生成一小批 STRM，并让 Emby 能读取这些文件。Docker 部署还要给 Emby 挂载相应目录，见 [文件权限相关问题](文件权限相关问题.md)。
2. 在 Emby 中将 STRM 所在目录加入对应类型的媒体库，运行一次媒体库扫描，确认影片已经出现。
3. 在 Emby 控制台的“高级 → API 密钥”创建密钥。
4. 打开 QMediaSync 的“系统设置 → Emby”，填写“Emby 服务器地址”和“Emby API Key”。例如地址为 `http://192.168.1.20:8096`，它必须能从 QMediaSync 所在机器或容器访问。
5. 点击“保存设置”。如果同时使用 Emby 302 代理，首次配置或更换 Emby 地址后，还需要重启 QMediaSync。
6. 开启“启用同步”。在“媒体库条目同步选择”中选择“全部媒体库”，或选择“指定媒体库”并勾选需要的库；点击“保存设置”。如果无法列出媒体库，先检查已保存的地址、密钥和连接状态。
7. 在页面下方“同步管理”中点击“启动全量同步”，等待完成。
8. 查看“最近全量同步”“最近成功同步”和“已同步 Item 数”。如果页面提示失败，检查同一时间的服务日志。

条目数量是 QMediaSync 已保存的 Emby 条目数，不是本轮新生成的 STRM 数量。影片很多时需要等待，不要连续重复启动。

## 自动同步如何设置

在同一页面设置“同步时间”，采用 5 段 Cron 表达式：`分 时 日 月 周`。例如 `0 * * * *` 表示每小时整点执行。页面会显示接下来 5 次执行时间，保存前可用它核对结果。

建议开启“每日首次全量同步”：每天首次符合条件的定时任务进行全量核对，当天已有成功的全量同步后，后续定时任务走增量同步。若当天全量同步失败，后续定时任务仍可能继续尝试全量同步。

按 [Emby 通知配置](Emby-通知配置.md) 配好 Webhook 后，新入库或受支持的修改通知还会触发单条同步；定时任务用于补充核对。刚接入 Emby、更换 Emby 服务或升级后需要补全关联时，可以手动执行一次全量同步。

“全部媒体库”会包含以后新增的库；“指定媒体库”只同步所选库的条目。这个选择**不是网盘联动删除的独立白名单**，删除功能还受通知范围、删除开关和文件核验约束，详见 [Emby 联动删除网盘文件](Emby-联动删除网盘文件.md)。

## 让 STRM 同步后自动刷新 Emby

完成上述全量条目同步后，在“系统设置 → Emby”开启“同步后刷新媒体库”，点击“保存设置”。

已保存的 STRM 同步目录成功同步后，如果新增了 STRM 或元数据下载任务，QMediaSync 会安排刷新对应的 Emby 条目或媒体库。上传后生成 STRM 也可能触发刷新；临时手动同步不在这个范围内。

刷新会等待相关的同步和下载任务结束，因此同步结束后不一定立即看到新影片；提交刷新成功也不代表 Emby 已经扫描完成。

如果新建媒体库或同步目录尚未建立关联，先让 Emby 扫描入库，再执行一次全量 Emby 条目同步。没有可用关联时，QMediaSync 可能无法确定该刷新哪个媒体库。

## 同步完成但 Emby 没有变化

- 点的是“启动全量同步”：它只更新 QMediaSync 保存的条目信息，先在 Emby 中扫描媒体库。
- STRM 还没有生成，或 Emby 看不到文件：检查 [生成 STRM](生成-STRM.md) 和 [文件权限相关问题](文件权限相关问题.md)。
- 下载队列仍在处理 NFO、图片等文件：等待下载结束，再检查 Emby。刷新长时间不满足条件时会自动取消本次刷新，不会强行扫描。
- STRM 内容没有变化：本轮可能不需要提交刷新；不要用“同步成功”来判断一定发生了刷新。
- Emby 已经有影片，但无法播放或没有时长：继续看 [无法播放问题的排查步骤](Emby-无法播放问题的排查步骤.md) 和 [Emby 媒体信息提取](Emby-媒体信息提取.md)。

“同步管理”显示的是条目同步状态，不是 Emby 扫库进度。Emby 是否正在扫描、扫描是否报错，应在 Emby 中查看。
