# Emby 媒体库同步

第一次接入 Emby 时，容易把几个“同步”混在一起。它们各自做的事情如下：

| 操作 | 做什么 | 从哪里操作 |
| --- | --- | --- |
| 生成 STRM | 把网盘或本地视频整理成 Emby 可以读取的 STRM 文件 | QMediaSync“STRM 同步”，见 [生成 STRM](生成-STRM.md) |
| Emby 扫描媒体库 | 让 Emby 发现 STRM，显示为电影或剧集 | Emby 媒体库扫描，或 QMediaSync 的“同步后刷新媒体库” |
| 同步 Emby 条目 | 把 Emby 已入库的条目信息记录到 QMediaSync，建立与网盘文件的关联 | QMediaSync“系统设置 → 媒体库 → Emby”中的“启动全量同步” |
| 提取媒体信息 | 请 Emby 读取时长、音轨等信息 | [Emby 媒体信息提取](Emby-媒体信息提取.md) |

**“启动全量同步”不会命令 Emby 扫库**；新影片没出现时，先检查 STRM 和 Emby 的媒体库扫描。

网盘目录移动或重新整理后，请先完成 STRM 同步，再让 Emby 扫描媒体库，最后同步 Emby 条目。使用外部 STRM 或两个程序的挂载路径不同时，先按 [STRM 存放和挂载要求](Emby-联动删除网盘文件.md#外部-strm-与不同挂载路径) 检查目录。

“系统设置 → 媒体库”中的 Emby、Jellyfin 和飞牛影视分别保存设置。Emby 与 Jellyfin 各连接一台服务器，可以同时启用；Jellyfin 的配置方法见 [Jellyfin 设置](Jellyfin-设置.md)。

## 第一次配置

1. 先准备一小批 STRM，并让 Emby 能读取这些文件。Docker 部署还要给 Emby 挂载相应目录，见 [文件权限相关问题](文件权限相关问题.md)。
2. 在 Emby 中将 STRM 所在目录加入对应类型的媒体库，运行一次媒体库扫描，确认影片已经出现。
3. 在 Emby 控制台的“高级 → API 密钥”创建密钥。
4. 打开 QMediaSync 的“系统设置 → 媒体库 → Emby”，开启“启用 Emby”，填写“Emby 服务器地址”和“Emby API Key”。例如地址为 `http://192.168.1.20:8096`，它必须能从 QMediaSync 所在机器或容器访问。
5. 点击“保存设置”。
6. 开启“启用同步”。在“媒体库条目同步选择”中选择“全部媒体库”，或选择“指定媒体库”并勾选需要的库；点击“保存设置”。如果无法列出媒体库，先检查已保存的地址、密钥和连接状态。
7. 在页面下方“同步管理”中点击“启动全量同步”，等待完成。
8. 查看“最近全量同步”“最近成功同步”和“已同步 Item 数”。如果页面提示失败，检查同一时间的服务日志。

媒体通知日志会注明“条目同步已完成”或“删除处理已完成”，并显示 `剧名 S01E06（ItemId ...）`；整季显示为 `剧名 S01`。删除处理完成表示本次通知已处理，实际删除或保留哪些文件，请查看同一通知的文件／目录结果。

条目数量是 QMediaSync 已保存的 Emby 条目数，不是本轮新生成的 STRM 数量。影片很多时需要等待，不要连续重复启动。

选库或保存后刷新出现“清理已删除媒体库记录”警告时，本次库清单仍可用，但 QMediaSync 的旧库记录清理未完成；保存后的警告不表示配置保存失败。检查同一时间的服务日志，处理原因后重新查询媒体库。

关闭“启用 Emby”并保存后，QMediaSync 停止本端后续同步、刷新、提取和事件处理，保留连接及分项设置；Jellyfin 和飞牛不受影响。升级前已有的 Emby 配置保持开启；如果原来在 Emby 设置中填写的是 Jellyfin，请自行改到 Jellyfin 标签并重新配置，不会自动搬迁。

## 自动同步如何设置

在同一页面设置“同步时间”，采用 5 段 Cron 表达式：`分 时 日 月 周`。例如 `0 * * * *` 表示每小时整点执行。页面会显示接下来 5 次执行时间，保存前可用它核对结果。

建议开启“每日首次全量同步”：每天首次符合条件的定时任务做全量核对；当天全量成功后，后续定时任务只做增量，全量失败时会继续尝试全量。

按 [Emby 通知配置](Emby-通知配置.md) 配好 Webhook 后，新入库或受支持的修改通知还会触发单条同步；定时任务用于补充核对。刚接入 Emby、更换 Emby 服务或升级后需要补全关联时，可以手动执行一次全量同步。

“全部媒体库”会包含以后新增的库；“指定媒体库”只同步所选库的条目。Emby 的合集不作为同步媒体库，其中引用的影片仍通过原电影或电视剧库同步；普通媒体库仅仅叫作“合集”不会被排除。这个选择只影响条目同步范围，与网盘联动删除无关，详见 [Emby 联动删除网盘文件](Emby-联动删除网盘文件.md)。

## 让 STRM 同步后自动刷新 Emby

完成上述全量条目同步后，在“系统设置 → 媒体库 → Emby”开启“同步后刷新媒体库”，点击“保存设置”。

已保存的 STRM 同步目录成功同步后，如果新增了 STRM 或元数据下载任务，QMediaSync 会安排刷新对应的 Emby 条目或媒体库。上传后 STRM 实际新增或更新也会触发刷新；在文件管理中临时生成的不触发。[STRM Webhook](STRM-Webhook.md) 还需由调用方显式开启刷新。

刷新会等待相关的同步和下载任务结束，同步结束后不一定立即看到新影片；是否扫描完成，以 Emby 中的实际结果为准。

如果新建媒体库或同步目录尚未建立关联，先让 Emby 扫描入库，再执行一次全量 Emby 条目同步。没有可用关联时，QMediaSync 可能无法确定该刷新哪个媒体库。
