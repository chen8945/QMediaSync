# 快速开始

第一次使用，建议先用一个只有少量影片的目录，走通“添加来源 → 生成 STRM → Emby 入库 → 播放”的流程。确认路径和设置正确后，再添加其他目录。

## 1. 安装并登录

按你的环境完成 [Docker 安装](Docker安装.md)、[Windows 安装使用](Windows-安装使用.md) 或 [Linux 安装使用](Linux-安装使用.md)。

首次使用先完成数据库配置；需要选择时看 [数据库的选择](数据库的选择.md)。启动日志出现一次性初始化码后，在登录页创建管理员，再用新账号登录。没有默认账号和密码，详细步骤见 [管理员与密码恢复](管理员与密码恢复.md)。

## 2. 准备来源和输出目录

网盘来源先在“网盘账号”中点击“添加账号”，完成授权并确认能浏览文件，见 [账号管理](账号管理.md)。本地目录直接在添加同步目录时选择本地来源。

准备一个供 QMediaSync 写入 STRM 的目录，并让 Emby 能读到同一批文件。需要分清：

| 名称 | 指的是什么 |
| --- | --- |
| 来源目录 | 视频所在的网盘或本地目录 |
| 目标路径 | QMediaSync 写入同步结果的本地位置 |
| STRM 存放目录 | 表单根据来源和目标计算的实际输出目录；保存前要核对 |
| Emby 中的媒体库路径 | Emby 自己能访问的路径，需要指向上面的实际输出文件 |

Docker 中应填写容器内路径。例如宿主机 `/srv/strm` 同时挂载为 QMediaSync 容器的 `/strm` 和 Emby 容器的 `/media`，两边路径虽然不同，实际读取的是同一份文件。设置 Emby 媒体库时，要使用它看到的 `/media` 下对应目录。

路径看不到或无法写入时，先处理 [文件权限相关问题](文件权限相关问题.md)。

## 3. 生成第一批 STRM

1. 打开“STRM 同步 → STRM 设置”，按 [生成 STRM](生成-STRM.md) 核对视频扩展名、最小体积和 STRM 地址。播放地址必须能被实际使用它的服务或客户端访问。
2. 进入“STRM 同步目录”，点击“添加同步目录”。选择来源、账号、来源路径和目标路径，核对表单里的“STRM 存放目录”，保存。
3. 115 网盘、百度网盘首次使用“全量同步”；OpenList、本地来源使用“同步”。
4. 到“STRM 同步记录”打开本次任务，查看生成结果及失败或跳过原因。启用了元数据下载时，再到“上传下载 → 下载队列”查看海报、字幕等文件的进度。
5. 在实际输出目录确认已生成 `.strm` 文件。用文本编辑器打开其中一个，检查地址是否是预期的 QMediaSync 地址或所选播放方式对应的地址。

没有生成文件时，先检查来源目录、扩展名、最小体积、排除规则和写入权限。任务完成但数量为 `0` 也可能表示没有需要处理的变化，具体解释见 [任务与通知](任务与通知.md)。

## 4. 让 Emby 读取并测试播放

1. 在 Emby 中添加或编辑媒体库，目录指向实际生成的 STRM 文件。电影与电视剧按 Emby 对应的媒体库类型分别管理。
2. 让 Emby 扫描媒体库，确认测试影片出现，再尝试播放。
3. 需要 QMediaSync 与 Emby 联动时，在 QMediaSync 的“系统设置 → Emby”填写 Emby 服务器地址和 Emby API Key，并按 [Emby 媒体库同步](Emby-媒体库同步.md) 保存配置、开启同步并完成一次全量条目同步。

希望使用内置 Emby 代理时，继续按 [Emby 外网 302](Emby外网302.md) 设置；首次启用代理或更改 Emby 地址后重启 QMediaSync，再让播放器连接代理地址。QMediaSync 网页地址、Emby 原始地址、Emby 代理地址用途不同，不能互相替代。

播放失败时，使用 [Emby 无法播放问题的排查步骤](Emby-无法播放问题的排查步骤.md)，从同一个客户端、同一个网络开始排查。

## 5. 再按需要开启其他功能

- 自动同步：在同步目录开启定时任务；全局与自定义 Cron 的区别见 [生成 STRM](生成-STRM.md)。
- 补充影视信息或整理名称：[刮削指南](刮削指南.md)。先确认需要的是仅刮削，还是会改名、移动文件的整理模式。
- 本地文件上传到 115 网盘：[目录监控上传](目录监控上传.md)。
- 自动提取媒体信息和处理 Emby 事件：[Emby 媒体信息提取](Emby-媒体信息提取.md)、[Emby 通知配置](Emby-通知配置.md)。
- 接收任务通知：[任务与通知](任务与通知.md)。
- 保护配置和数据：设置 [备份与恢复](备份与恢复.md)，并把备份保存到独立位置。

以后查找功能和排障说明，可以回到 [使用手册首页](Home.md)。
