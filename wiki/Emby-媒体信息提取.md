# Emby 媒体信息提取

媒体信息包括视频时长、编码、音轨和字幕轨道等。STRM 入库后，这些信息可能还没有读出来，部分客户端会出现进度条不完整、起播慢或无法选择音轨的情况。QMediaSync 可以向 Emby 发起读取请求，帮助它补齐信息；最终能否播放，还取决于链接、网络和客户端对格式的支持。

如果影片还没有出现在 Emby 中，先按 [Emby 媒体库同步](Emby-媒体库同步.md) 完成入库。提取媒体信息不会替你创建媒体库，也不会生成 STRM。

## 手动提取已有影片

1. 在 Emby 控制台的“高级 → API 密钥”中新建密钥，应用名称可填写 `QMediaSync`。
2. 打开 QMediaSync 的“系统设置 → Emby”，填写“Emby 服务器地址”和“Emby API Key”。地址应能从 QMediaSync 所在机器或容器访问，例如 `http://192.168.1.20:8096`，不要填写网页末尾的 `/web/index.html`。
3. 点击“保存设置”。如果同时使用 Emby 302 代理，首次配置或更换 Emby 地址后，还需要重启 QMediaSync。
4. 点击页面底部的“提取媒体信息”。系统会扫描 Emby 全部媒体库，找出尚未提取媒体信息的项目并加入队列。
5. 到“上传下载 → 下载队列”查看来源为“Emby 媒体信息提取”的记录。
6. 处理后打开 Emby 中的影片详情，确认时长、音轨等信息，再用实际播放器试播。

手动提取的范围不受“媒体库条目同步选择”限制。扫描正在运行时，无需反复点击按钮。队列显示完成表示本次请求已处理，不能单凭这个状态认定所有媒体信息都已补齐。

## 自动提取新入库的影片

1. 按 [Emby 通知配置](Emby-通知配置.md) 配好 Webhook，并勾选“已添加新媒体”。
2. 在 QMediaSync 的“系统设置 → Emby”开启“入库后提取媒体信息”。
3. 点击“保存设置”。

后续收到 Emby 的电影或剧集入库通知时，QMediaSync 才会为对应条目安排提取。**仅仅生成了新的 STRM 文件，不会直接触发自动提取**；还需要 Emby 扫描入库并成功发送通知。

如果已经用其他 Emby 插件提取媒体信息，可以关闭 QMediaSync 的“入库后提取媒体信息”，避免重复处理。请按插件自己的说明配置，**不要因此删除 Emby API Key**：媒体库条目同步、刷新及部分通知功能也需要它。

## 没有进度或提取后仍不正常

- 下载队列没有对应记录：手动提取可能没有找到缺少信息的条目；自动提取则先检查入库通知是否送达、开关是否已保存。
- 队列记录失败：查看详情和同一时间的 QMediaSync、Emby 日志，确认 Emby 地址、密钥和 STRM 链接可用。
- 队列完成但时长仍不对：到 Emby 详情页确认实际结果，再按 [无法播放问题的排查步骤](Emby-无法播放问题的排查步骤.md) 检查链接和播放器。
- 较早记录不见了：下载队列中超过 7 天的记录会定期清理；需要排查时及时保存已脱敏的日志。
