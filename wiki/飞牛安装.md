本文介绍通过飞牛 fnOS 应用中心安装和管理 QMediaSync。若准备在飞牛上使用 Docker，请阅读 [Docker 安装](Docker安装.md)；两种方式的目录和权限设置不同。

## 1. 选择安装包

先查看你的飞牛设备架构，并在 [QMediaSync 发布页面](https://github.com/chen8945/QMediaSync/releases) 的附件中查找对应的 FPK：

| 设备架构 | 安装包 |
| --- | --- |
| x86-64，常见 Intel 或 AMD 设备 | `QMediaSync_amd64.fpk` |
| ARM64 | `QMediaSync_arm64.fpk` |

并非每个版本都提供 FPK，以该次发布的附件为准。没有 FPK 时，可以改用 [Docker 安装](Docker安装.md)，不要把 Linux 压缩包当作 FPK 上传。

如果你的应用中心提供 QMediaSync，先核对应用介绍中的项目来源和版本；本页不假定某个版本已在应用中心上架。已有对应 FPK 时，可打开应用中心的“手动安装”，选择 `.fpk` 文件并按向导继续；手动安装入口见 [飞牛官方应用安装说明](https://developer.fnnas.com/docs/quick-started/test-application/)。

## 2. 在安装向导选择数据库

FPK 安装向导会询问数据库类型，默认选择 SQLite。

- **SQLite**：不需要安装数据库服务。后续 PostgreSQL 连接字段可以不填，继续完成安装即可。
- **PostgreSQL**：先准备 PostgreSQL 15 及以上服务，再填写实际连接信息。应用本身不会替你安装 PostgreSQL。

选择 PostgreSQL 时填写：

| 项目 | 填写内容 |
| --- | --- |
| 主机地址 | 数据库所在主机的可达 IP 或域名 |
| 端口号 | 数据库实际监听或发布的端口 |
| 用户名 | 有权访问 QMediaSync 数据库的用户 |
| 密码 | 该数据库用户的实际密码，不沿用向导中的示例密码 |
| 数据库名称 | QMediaSync 使用的独立数据库名，例如 `qmediasync` |

如果 PostgreSQL 在同一台飞牛设备的 Docker 中，按 [Docker 安装](Docker安装.md) 页面末尾的独立数据库示例部署后，主机填 `127.0.0.1`，端口填 `15432`。FPK 应用运行在宿主机上，不能直接使用 Docker 网络里的 `postgres` 服务名。

安装向导会生成配置文件，因此正常安装完成后通常直接进入创建管理员页面，无需再做一次浏览器数据库配置。如果启动失败，先查看日志，核对数据库地址、密码和权限。

## 3. 启动并创建管理员

1. 在飞牛应用中心启动 QMediaSync，从桌面应用入口打开，或在浏览器使用飞牛的局域网 IP 访问，例如 `http://192.168.1.10:12333`。
2. 在飞牛文件管理器找到应用共享目录 `qmediasync`，打开其中的 `config/logs/app.log`。不同存储空间的完整路径可能不同，不要照搬别人的 `/vol1/...` 路径。
3. 在最新一次启动日志中找到“检测到系统尚未创建管理员，请使用以下初始化码完成首次管理员创建”，复制后面的初始化码。
4. 在网页“创建管理员”表单中填写初始化码、用户名和密码。用户名为 3～20 个英文字母或数字；密码至少 6 个字符，不能是纯数字或纯字母。
5. 创建成功后，使用新账号登录，再按 [快速开始](快速开始.md) 完成基础设置。

初始化码只在本次启动期间有效。创建前重启过应用，就需要从最新日志重新取码；已有管理员时不会再生成初始化码。

如果找不到共享目录或日志，查看应用启动输出中的“当前配置文件目录”，以该路径为准。正常情况下配置位于应用共享目录的 `config/`，旧安装或平台未提供共享路径时可能使用平台配置目录。首次初始化请在可信的局域网内完成。

## 4. 授权媒体目录

能在飞牛文件管理器看到一个文件夹，不代表 QMediaSync 已有权限访问它。

1. 在飞牛应用中心找到 QMediaSync，打开应用设置中的目录访问授权。
2. 授权需要使用的目录：生成 STRM、图片和 NFO 的目标目录需要写入权限；只读取本地挂载文件的来源目录至少需要读取权限。启用源文件删除等功能时，来源也需要相应写入权限。
3. 回到 QMediaSync，重新打开本地目录选择器，确认已授权的目录能够显示。
4. 如果 Emby 也要读取生成的文件，再单独给 Emby 授权对应目录。

飞牛应用通过平台管理访问权限，具体机制见 [飞牛官方权限说明](https://developer.fnnas.com/docs/core-concepts/privilege/)。无需给 FPK 应用设置 Docker 的 `GUID`、`GPID` 或 `/app/config` 挂载。目录仍不可写时，见 [文件权限相关问题](文件权限相关问题.md)。

## 数据放在哪里

| 内容 | 位置和用途 |
| --- | --- |
| 主配置 | 实际配置目录中的 `config.yaml` |
| SQLite 数据库 | 默认是配置目录中的 `qmediasync.db` |
| 本机加密密钥 | 配置目录中的 `encryption.key`，迁移时必须保留 |
| 日志 | 配置目录中的 `logs/`，主日志默认是 `app.log` |
| STRM 和元数据 | 你在同步目录中选择的目标路径 |
| PostgreSQL 数据 | 独立数据库服务的数据目录，不在 FPK 安装目录中 |

共享目录由飞牛按安装位置创建，应用可以通过平台提供的路径访问。见 [飞牛官方共享目录说明](https://developer.fnnas.com/docs/core-concepts/resource/)。备份时保留整个配置目录，并按 [备份与恢复](备份与恢复.md) 备份数据库；单独保留 FPK 安装包不能恢复账号和同步设置。

## 停止、重启、更新和卸载

日常启停在飞牛应用中心操作。需要重启时，停止后再启动 QMediaSync；备份恢复完成后如果页面提示手动重启，也按这个方法执行。

飞牛环境下，QMediaSync 的更新页会提示到应用商店更新。请在飞牛应用中心核对可用版本；手动安装的版本按对应 FPK 发布说明和平台提供的升级方式处理。更新前先备份，见 [更新与旧版迁移](更新与旧版迁移.md)。

卸载向导会询问是否删除应用数据，默认不删除。选择删除会移除应用共享目录下的 `config/`；其中可能包含 SQLite 数据库、密钥和本地备份。需要保留数据时选“否”，并提前把备份复制到应用目录以外。外置 PostgreSQL 数据和自选媒体目录也需要分别管理。

安装完成后，检查能否登录、是否能在授权目录写入 STRM，以及重启后配置是否保留。忘记密码见 [管理员与密码恢复](管理员与密码恢复.md)，管理页面的 HTTPS 和域名配置见 [反向代理配置](反向代理配置.md)。
