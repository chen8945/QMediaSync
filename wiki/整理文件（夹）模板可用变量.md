# 整理文件和文件夹的命名模板

在「刮削 & 整理 → 刮削目录」中添加或编辑目录，可以分别设置「文件夹重命名模板」和「文件重命名模板」。模板决定整理后的名称；选择「仅刮削」时不改名，模板也不会生效。完整操作见 [刮削指南](刮削指南.md)。

第一次使用可以先复制下面的模板，在少量文件上确认结果。

| 用途 | 模板 | 示例结果 |
| --- | --- | --- |
| 电影文件夹或文件名 | `{title} ({year})` | `星际穿越 (2014)` |
| 电视剧文件夹 | `{title} ({year})` | `示例剧集 (2024)` |
| 电视剧文件名 | `{title} - {season_episode} - 第 {episode_number} 集` | `示例剧集 - S01E01 - 第 1 集` |

文件名模板填写的是**不含扩展名的名称**，程序会在末尾追加原视频扩展名。例如第一行用于 `.mkv` 文件时，最终文件名为 `星际穿越 (2014).mkv`。电视剧还会创建 `Season 1` 这样的季目录；开启二级分类后，会在影视剧目录前增加分类目录。

## 两种写法怎么选

只需要拼接名称时，用单花括号写法即可：

```text
{title} ({year}) [{resolution}]
```

需要“有年份才加括号”“有演员才加后缀”时，可以用双花括号和条件语句：

```django
{{title}}{% if year %} ({{year}}){% endif %}{% if actors %} - {{actors}}{% endif %}
```

例如，有年份和两位演员时可以得到 `星际穿越 (2014) - 马修·麦康纳, 安妮·海瑟薇`；缺少年份和演员时只保留标题。

程序会自动判断写法，不需要切换开关：模板同时包含 `{{` 和 `}}`，或包含 `{% if`，才会进入新模板引擎。新引擎使用 **Pongo2 v6**，语法与 Django 模板相近；不能把其他软件的 Jinja2 模板原样搬过来并假定所有变量、过滤器都可用。也不要在同一模板里混用单花括号占位符和双花括号表达式。

## 通用变量

下表是新语法的变量名，例如 `title` 写成 `{{title}}`。这些变量也可使用单花括号，例如 `{videoFormat}` 和 `{{videoFormat}}` 的取值相同。

变量是否有值取决于识别结果、媒体信息和 NFO；表中的示例不代表每个文件都能取得该信息。

| 变量名 | 含义 | 示例值 |
| --- | --- | --- |
| `title` | 当前识别出的影视剧标题，不保证一定为中文 | 星际穿越 |
| `year` | 发行年份 | 2014 |
| `tmdbid` | 纯数字 TMDB ID | 157336 |
| `videoFormat` | 视频分辨率 | 1080p、2160p |
| `edition` | 分辨率等级 | FHD、UHD |
| `fileExt` | 原视频扩展名，包含开头的点 | `.mkv` |
| `original_name` | 原视频文件名，**包含扩展名** | `Interstellar.2014.mkv` |
| `original_title` | 作品的原始标题，可以是英文、中文、日文等 | Interstellar |
| `original_language` | 作品的原始语言代码 | en、zh、ja |
| `imdbid` | IMDb ID | tt0816692 |
| `runtime` | 时长，单位为分钟 | 169 |
| `overview` | 剧情简介，通常较长，不适合直接用作文件名 | 一群探险家利用虫洞进行星际旅行 |
| `vote_average` | 评分 | 8.600000 |
| `videoCodec` | 视频编码 | h264、hevc |
| `audioCodec` | 第一条音轨的编码 | aac、dts |
| `actors` | 按下述规则生成的演员文字 | 马修·麦康纳, 安妮·海瑟薇 |
| `actor` | `actors` 的历史别名，两者结果相同 | 同上 |
| `num` | 番号或媒体编号，有相应信息时才有值 | ABCD-1234 |

`original_name` 和 `fileExt` 已经包含扩展名，直接放进文件名模板可能得到 `.mkv.mkv` 这样的重复后缀。**想保留原文件名时，清空「文件重命名模板」即可。**

### 演员怎么显示

`actor` 和 `actors` 在两种语法中遵循相同规则：

| 演员数量 | 输出 |
| --- | --- |
| 0 位 | 空字符串 |
| 1 位 | 演员姓名 |
| 2 位 | 两个姓名，用英文逗号和空格连接，如 `张三, 李四` |
| 3 位及以上 | `多人演员` |

这里统计的是媒体信息中的演员数量。演员很多时，模板不会展开整份名单。

## 电视剧专用变量

| 新语法变量名 | 含义 | 示例值 |
| --- | --- | --- |
| `season` | 季号，不补零 | 2 |
| `episode` | 集号，不补零 | 8 |
| `season_episode` | 补齐两位的季集编号 | S02E08 |
| `episode_title` | 本集标题 | 示例集标题 |
| `season_year` | 季年份；没有季信息时尝试使用集信息中的年份 | 2024 |

例如：

```django
{{title}} {{season_episode}}{% if episode_title %} - {{episode_title}}{% endif %}{% if videoFormat %} [{{videoFormat}}]{% endif %}
```

可以得到 `示例剧集 S02E08 - 示例集标题 [1080p]`。

## 单花括号写法的专有变量

除了前面的通用变量，单花括号写法还支持以下历史变量。这些写法有自己的格式，不要只把括号改成双花括号。

| 写法 | 含义 | 示例结果 |
| --- | --- | --- |
| `{resolution}` | 视频分辨率，对应新语法的 `videoFormat` | 2160p |
| `{resolution_level}` | 分辨率等级，对应新语法的 `edition` | UHD |
| `{bitrate}` | 视频码率，以整数 Mbps 输出 | `20Mbps` |
| `{tmdb_id}` | 带媒体服务器识别标记的 TMDB ID；没有 ID 时为空 | `{tmdbid-157336}` |
| `{season_number}` | 季号，不补零 | 1 |
| `{episode_number}` | 集号，不补零 | 1 |
| `{episode_name}` | 本集标题，对应新语法的 `episode_title` | 示例集标题 |

注意下面两种结果不同：

| 模板 | 结果 |
| --- | --- |
| `S{season_number}E{episode_number}` | `S1E1` |
| `{season_episode}` | `S01E01` |

需要 Emby 常见的季集编号格式时，直接使用 `{season_episode}`。

## 留空、缺少信息和特殊字符

- **模板留空**：文件名保留原名；文件夹名优先沿用原目录，没有可用原目录时自动生成。例如，散放的电影会尝试用 `{title} ({year})` 创建影片目录。
- **模板渲染后为空**：回退到原名称，避免生成只剩 `.mkv` 后缀的文件。电影文件夹优先保留原文件夹名，否则使用原视频名；电视剧文件夹还会尝试使用剧名。
- **单花括号里的未知变量**：无法取值的占位符可能原样留在名称中，并写入日志。例如把电视剧专用变量用在电影上，文件名里可能原样出现 `{season_episode}` 这串文字。应按媒体类型选择变量。
- **新语法中的特殊字符**：Pongo2 默认做 HTML 转义，标题 `A&B` 经 `{{title}}` 会变成 `A&amp;B`。希望保留原字符时可写 `{{title|safe}}`。
- **评分格式**：`vote_average` 可能输出 `8.600000`。不要直接套用其他模板引擎的格式化过滤器。
- **目录层级**：模板可以使用相对层级，不能填写绝对路径、反斜杠或 `..`。目标根目录应在「目标路径」中选择。

模板修改后不会自动给已经整理好的文件批量改名。先用少量待处理文件确认结果，再用于整个目录。

## “其他”类型的信息来自哪里

媒体类型为「其他」时只能整理，名称、年份、番号和演员来自视频旁的 NFO，程序不会为它查询 TMDB。

需要先准备对应的 `<视频文件名>.nfo`，或者同目录的 `movie.nfo`、`tvshow.nfo`、`season.nfo` 等受支持的 NFO。没有 NFO 的视频会被跳过。标题依次尝试 `title`、`originaltitle`、`sorttitle`，都没有时使用原视频名；年份依次尝试 `year`、`premiered`、`releasedate`、`aired`。番号依次尝试 `num`、`uniqueid[type=num]`、`code`、`id`，其中 `code` 和 `id` 需要同时包含字母和数字，且不能是 `tt` 加数字的 IMDb ID。

如果 NFO 没有演员或番号，`{actors}`、`{num}` 就不会凭空生成内容。先检查 NFO，再调整模板。
