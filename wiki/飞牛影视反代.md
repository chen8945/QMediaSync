# 飞牛影视

如果你已经用飞牛影视管理 STRM，想继续使用 QMediaSync 的取链和播放设置，可以开启「飞牛影视反代」，通过新的入口打开飞牛影视网页，或连接兼容播放器。

功能默认关闭。当前支持飞牛影视的 Emby 兼容 STRM 播放，以及飞牛影视 0.9.8 的自带网页 STRM 直接播放。其他版本、手机和电视客户端请按下文步骤试播。

账号的播放、下载和转码权限仍按飞牛设置执行；播放器请求转码时，使用飞牛提供的转码方式。

## 开启前准备

- 飞牛影视已经运行，并能用原来的账号正常登录和播放。
- QMediaSync 能连接飞牛影视，且能读取同一批 STRM 文件。
- Docker 用户先挂载 STRM 文件夹；fnOS 原生应用先给 QMediaSync 授权该文件夹。路径和权限问题见 [文件权限相关问题](文件权限相关问题.md)。

## 在网页中配置

1. 打开 QMediaSync 的「系统设置 → 飞牛影视」。
2. 开启「启用反代」。
3. 填写**原飞牛影视服务的根地址**，例如 `http://192.168.1.20:8005`。
4. 路径相同可以先不添加映射；两端路径不同时，按下一节填写对应文件夹。
5. 点击保存，程序会立即应用飞牛设置，**无需重启 QMediaSync**。
6. 查看页面上方的运行状态和保存结果。如果提示“已保存但未应用”，按错误说明处理后再次保存。

启停、修改飞牛地址或路径映射后保存，会短暂中断该入口的播放和长连接；保存失败时原有状态不变。

Docker 需映射容器端口 `9005`，例如在原 Compose 的 `ports` 中增加 `"19005:9005"`，播放器随后访问宿主机的 `19005`。保留原来的配置与挂载，按原方式更新容器，并按需要放行防火墙或路由器端口。

## 路径映射怎么填

映射用于告诉 QMediaSync：飞牛影视中的这个文件夹，对应 QMediaSync 能读取的哪个文件夹。

比如同一份 STRM 文件：

```text
飞牛影视看到： /vol1/media/strm/电影/示例电影.strm
QMediaSync 看到：/media/strm/电影/示例电影.strm
```

添加一条：

| 设置 | 示例 |
| --- | --- |
| 飞牛影视中的 STRM 文件夹 | `/vol1/media/strm` |
| QMediaSync 中的 STRM 文件夹 | `/media/strm` |

只需填写不同的文件夹前缀，后面的 `电影/示例电影.strm` 会保留，通常不需要每部影片添加一条。可以添加多组，但飞牛一侧不要重复或相互包含。

QMediaSync 一侧可以点击「选择文件夹」，也可以手动输入；飞牛一侧按它实际看到的路径填写。Docker 中填写 QMediaSync **容器内路径**，选好后点击主页面保存。

两端路径相同、文件位于 QMediaSync 已知输出目录时，通常无需映射。无法自动匹配时，按两端实际路径填写映射，并确认 QMediaSync 已挂载该目录且有读取权限。

## 在播放器中连接

假设 QMediaSync 的局域网地址为 `192.168.1.10`，Docker 使用上面的 `"19005:9005"` 映射：

```text
http://192.168.1.10:19005
```

在浏览器打开这个入口，即可使用飞牛影视自带网页；也可以在支持飞牛影视 Emby 兼容协议的播放器中填写它。使用**原飞牛影视账号**登录。直接运行 QMediaSync 时使用端口 `9005`；Docker 使用实际映射的宿主机端口。

依次确认：能登录、能看到媒体库、STRM 可以播放、字幕正常、拖动进度可用，原来的本地视频也能正常播放。需要外网播放时，再用外网设备测试。

STRM 中使用当前 QMediaSync 的内网播放地址时，可以通过反代入口播放。

## 提前准备播放链接

在「STRM 同步 → STRM 设置」开启“启用 STRM 预加载”并保存，飞牛设置中的链接也可直接前往。它与 Emby 302 共用一个开关，默认关闭，作用和触发时机见 [提前准备播放链接](生成-STRM.md#提前准备播放链接)。

请从飞牛反代入口访问。首次打开或服务重启后也会尝试准备，同一设备正常播放后会参考实际播放方式；更换播放器可能需要重新取链，仍可直接点击播放。当前飞牛原生网页的播放记录不足以可靠判断下一集，暂不据此提前加载下一集或猜测电影分段；兼容播放器的效果需按实际客户端验证。

## 常见问题

| 现象 | 先检查什么 |
| --- | --- |
| 保存后入口打不开 | 查看实际错误；排除 `9005` 占用后再次保存，并检查 Docker 发布和防火墙；普通保存无需重启 |
| 地址填好却反复跳转或打不开 | 是否把原飞牛影视地址填成了反代自身、QMediaSync 或 Emby 端口 |
| 能登录、看见媒体但 STRM 不生效 | 确认使用反代入口；检查账号播放设置、两端 STRM 路径和挂载权限。飞牛影视 0.9.8 的部分客户端连接可能只返回网页，需核对客户端连接方式和版本 |
| 能播放但下载未被接管 | 检查飞牛账号的下载权限 |
| 暂停、退出正常，但重新打开仍从头播放 | 检查飞牛识别的影片时长；若为 0，先修正时长识别，再测试续播 |
| 文件同名但没有自动匹配 | 按实际挂载填写两端的根目录映射 |
| 取得地址却不能播放 | 从播放器所在网络检查外部地址或最终视频地址，核对原来的网盘授权及播放代理设置 |
| 修改 STRM 后仍有旧结果 | 核对修改的是两端使用的同一文件，且文件内链接有效；必要时关闭并保存，再启用并保存以清理缓存，这会中断该入口播放 |
| 换机器或恢复后不能用 | 恢复后重启，再核对端口映射、挂载和路径映射；端口冲突时按页面错误处理。不含飞牛配置的旧备份恢复后，需重新开启 |

飞牛配置随数据库备份，STRM 文件需另行保留，操作见 [备份与恢复](备份与恢复.md)。错误通过现有日志页面和程序日志查看。

反馈时提供 QMediaSync 与飞牛影视版本、客户端、错误时间和部署方式；遮住密码、Token、Cookie、私钥及带签名的播放链接。
